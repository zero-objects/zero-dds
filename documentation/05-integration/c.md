# C

The C-FFI is the long-term-stable contract. Every other non-Rust
binding sits on top of it.

## Header

`zerodds.h` (generated by `zerodds-c-api/build.rs` via cbindgen).
Distributed in `libzerodds-dev` package or
`crates/zerodds-c-api/include/zerodds.h` from source.

## Linking

```bash
cc your_app.c -lzerodds -o your_app
```

Or with `pkg-config` (once a `.pc` file ships alongside the C
ABI library):

```bash
cc $(pkg-config --cflags --libs zerodds) your_app.c -o your_app
```

## API model — opaque handles

```c
typedef struct ZeroDdsRuntime  ZeroDdsRuntime;
typedef struct ZeroDdsWriter   ZeroDdsWriter;
typedef struct ZeroDdsReader   ZeroDdsReader;
```

Every object is created via a `*_create` function and destroyed
via `*_destroy`. Failed creates return `NULL`.

## Hello, world

```c
#include <zerodds.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

int main(void) {
    ZeroDdsRuntime* rt = zerodds_runtime_create(/* domain */ 0);
    if (!rt) { fprintf(stderr, "runtime_create failed\n"); return 1; }

    ZeroDdsWriter* w = zerodds_writer_create(rt, "Hello", "RawBytes",
                                             /* reliable */ 1);
    if (!w) { fprintf(stderr, "writer_create failed\n"); return 2; }

    if (zerodds_writer_wait_for_matched(w, 1, 5000) != 0) {
        fprintf(stderr, "no subscriber matched\n"); return 3;
    }

    const char* msg = "hello from C";
    if (zerodds_writer_write(w, (const uint8_t*) msg, strlen(msg)) != 0) {
        fprintf(stderr, "write failed\n"); return 4;
    }

    zerodds_writer_destroy(w);
    zerodds_runtime_destroy(rt);
    return 0;
}
```

Subscriber:

```c
ZeroDdsReader* r = zerodds_reader_create(rt, "Hello", "RawBytes", 1);

uint8_t* buf = NULL;
size_t   len = 0;
while (1) {
    int rc = zerodds_reader_take(r, &buf, &len);
    if (rc == 0 && buf != NULL) {
        printf("got: %.*s\n", (int)len, (const char*) buf);
        zerodds_buffer_free(buf, len);
    }
    usleep(10 * 1000);
}
```

## Memory ownership

| Object | Created by | Destroyed by |
|---|---|---|
| `ZeroDdsRuntime` | `zerodds_runtime_create` | `zerodds_runtime_destroy` |
| `ZeroDdsWriter` | `zerodds_writer_create` | `zerodds_writer_destroy` |
| `ZeroDdsReader` | `zerodds_reader_create` | `zerodds_reader_destroy` |
| Sample buffer (out-arg of `take`) | runtime | `zerodds_buffer_free(buf, len)` |

All `*_destroy` functions are NULL-tolerant.

## Status codes

```c
typedef enum {
    ZERODDS_OK                  =  0,
    ZERODDS_ERROR               = -1,
    ZERODDS_BAD_HANDLE          = -2,
    ZERODDS_INVALID_UTF8        = -3,
    ZERODDS_TIMEOUT             = -4,
    ZERODDS_PRECONDITION_NOT_MET = -5,
} ZeroDdsStatus;
```

## Threading

`ZeroDdsRuntime` is internally thread-safe; you can call any
function from any thread. Per-handle (`ZeroDdsWriter`,
`ZeroDdsReader`) calls are serialised by the runtime — multiple
threads writing to the same handle are safe but interleave.

## Type system — CDR is on you

The C-FFI is byte-oriented. `zerodds_writer_write(w, bytes, len)`
takes the already-CDR-encoded payload. Encode / decode in your
application — typically via stubs from `zerodds-idlc --cpp` or hand-
rolled CDR for plain types.

This trade-off is intentional: keeps the C surface small and
makes wire-drift testing trivial (every byte is exposed).

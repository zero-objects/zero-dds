# C++

`zerodds-cpp` provides a C++17 RAII wrapper over the C-FFI plus
template-based CDR encode/decode for IDL-generated types.

## CMake

```cmake
find_package(zerodds REQUIRED)         # provided by libzerodds-dev
add_executable(myapp main.cpp Robot.cpp)
target_link_libraries(myapp zerodds::cpp)
```

For now (pre-release) without find_package:

```cmake
target_include_directories(myapp PRIVATE /usr/local/include)
target_link_libraries(myapp /usr/local/lib/libzerodds.so)
```

## Header

```cpp
#include <zerodds/zerodds.hpp>
```

## Hello, world

```cpp
#include <zerodds/zerodds.hpp>
#include <iostream>
#include <chrono>
#include <thread>

int main() {
    using namespace std::chrono_literals;

    auto rt = zerodds::Runtime::create(0);
    if (!rt) { std::cerr << "runtime\n"; return 1; }

    auto w = rt->create_writer("Hello", "RawBytes", /*reliable*/true);
    if (!w) return 2;

    if (!w->wait_for_matched(1, 5s)) {
        std::cerr << "no subscriber\n"; return 3;
    }

    std::string msg = "hello from C++";
    w->write(msg.data(), msg.size());
    return 0;
}
```

Subscriber with `std::vector<uint8_t>` ownership:

```cpp
auto r = rt->create_reader("Hello", "RawBytes", true);
while (true) {
    if (auto buf = r->take()) {                // std::optional
        std::cout << "got: "
                  << std::string_view(
                       reinterpret_cast<char*>(buf->data()),
                       buf->size())
                  << "\n";
    }
    std::this_thread::sleep_for(10ms);
}
```

## Type-safe API with IDL stubs

`zerodds-idlc` emits one `Type.hpp` per `.idl` file. The generated
class implements the `zerodds::TopicType` concept — so
`Writer<T>` / `Reader<T>` work directly:

```cpp
#include <zerodds/zerodds.hpp>
#include "Robot.hpp"   // generated by zerodds-idlc --cpp

auto w = rt->create_typed_writer<robot::Pose>("Telemetry");
robot::Pose p { .id = "robot-01", .x = 1.0, .y = 2.0, .z = 0.0 };
w->write(p);   // CDR encode happens here
```

## RAII semantics

Every wrapper owns its underlying handle and cleans up in its
destructor. The wrappers are move-only — copies are deliberately
disabled to prevent double-free.

## Error handling

C++ wrappers return `std::optional<T>` for fallible creates and
`zerodds::Result<T>` (Rust-style `Result`-template) for fallible
operations. No exceptions thrown across the FFI boundary.

## Build flags

| Flag | Effect |
|---|---|
| `-DZERODDS_NO_EXCEPTIONS` | Compile-time disable of exception-using helpers |
| `-DZERODDS_HEADER_ONLY` | Wrapper inlined into header |

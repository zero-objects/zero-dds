# Java

Two layers: the JNI binding (`zerodds-java-jni`) speaks to the Rust
runtime, and the `org.omg.dds.*` PSM (`zerodds-java-omgdds`) provides
the spec-compliant API surface.

## Maven

```xml
<dependency>
  <groupId>io.zerodds</groupId>
  <artifactId>zerodds</artifactId>
  <version>0.0.0-pre</version>
</dependency>
```

Until the artifact lands on Central, build from
`crates/java/` and install locally with `mvn install`.

## Native library loading

The JNI binding ships `libzerodds-jni.so` / `.dylib` / `.dll` in
the JAR's `META-INF/native/<arch>-<os>/`. The class
`io.zerodds.NativeLoader` extracts and loads at runtime — no
manual `System.loadLibrary` needed.

## Hello, world (low-level JNI binding)

```java
import io.zerodds.zero.*;

public class Hello {
    public static void main(String[] args) throws Exception {
        try (Runtime rt = Runtime.create(0);
             Writer w = rt.createWriter("Hello", "RawBytes", true)) {

            if (!w.waitForMatched(1, java.time.Duration.ofSeconds(5))) {
                System.err.println("no subscriber");
                return;
            }

            byte[] msg = "hello from Java".getBytes("UTF-8");
            w.write(msg);
        }
    }
}
```

## OMG DDS Java PSM

`org.omg.dds.*` is the spec-defined API. It looks identical to
RTI Connext / OpenSplice Java code:

```java
import org.omg.dds.core.*;
import org.omg.dds.domain.*;
import org.omg.dds.pub.*;
import org.omg.dds.topic.*;

DomainParticipantFactory factory = DomainParticipantFactory.getInstance();
DomainParticipant dp = factory.createParticipant(0);

Topic<Pose> topic = dp.createTopic("Telemetry", Pose.class);
Publisher pub = dp.createPublisher();
DataWriter<Pose> writer = pub.createDataWriter(topic);

writer.write(new Pose("r1", 1.0, 2.0, 3.0));
```

`Pose` is generated by `zerodds-idlc Robot.idl --java`.

## Generated types from IDL

```
gen/java/com/example/robot/
├── Pose.java                     # POJO with @TopicType
└── Telemetry.java
```

Each class implements `dds.types.TopicType`, has `serialize` /
`deserialize` methods, and a `@DDSKey`-marked field set.

## Threading

Per JLS the JVM is itself thread-safe; the JNI binding wraps the
runtime such that all Java threads share one `DcpsRuntime`. Multi-
threaded publish / subscribe works without app-level locks.

## QoS

```java
DataWriterQos qos = DataWriterQos.copyFromTopicQos(topic.getQos());
qos = qos.withPolicy(qos.getReliability().withKind(ReliabilityKind.RELIABLE))
         .withPolicy(qos.getDurability().withKind(DurabilityKind.TRANSIENT_LOCAL));
DataWriter<Pose> w = pub.createDataWriter(topic, qos);
```

The fluent QoS builder mirrors the OMG DDS Java PSM
specification (formal/2024-..-..).

## Listeners

```java
DataReader<Pose> reader = sub.createDataReader(topic);
reader.setListener(new DataReaderListener<Pose>() {
    @Override public void onDataAvailable(DataReader<Pose> r) {
        SampleIterator<Pose> samples = r.take();
        while (samples.hasNext()) {
            Pose p = samples.next().getData();
            System.out.println(p);
        }
    }
});
```

## Spring / Quarkus

Wire `DomainParticipant` as a bean:

```java
@Configuration
public class DdsConfig {
    @Bean(destroyMethod = "close")
    public DomainParticipant participant() {
        return DomainParticipantFactory.getInstance().createParticipant(0);
    }
}
```

# IDL examples

A handful of canonical schemas. Use as a starting point; compile
with `zerodds-idlc <file>.idl --<lang> -o gen/`.

| File | Demonstrates |
|---|---|
| [Robot.idl](Robot.idl) | Plain structs, enums, unions, bitmask, sequences, `@key`, `@optional`, multiple extensibility kinds |

More to come (state machines, time-series, RPC patterns).

**ZeroDDS publishes its first two formal Vendor Specifications.**

We are excited to announce the public Beta release of two
ZeroDDS Vendor Specifications, written in the inhaltlichen style
of the OMG DDS Core Specifications:

🔹 **DDS-AMQP 1.0** — a normative bridge between OMG DDS and OASIS
AMQP 1.0, with three conformance profiles (Endpoint, Bridge,
Codec). Define DDS↔AMQP gateways without bespoke connector
applications.

🔹 **DDS-TS 1.0** — a TypeScript Platform-Specific Model for OMG
IDL 4.2, peer to the OMG-defined C++/C#/Java mappings. Brings
ZeroDDS topic types directly into browser- and Node.js-side
TypeScript code.

This positions ZeroDDS as a **First-Party Spec-Author** in the
DDS landscape. We are not only an implementation of OMG
specifications, we **author specifications other implementations
can follow**.

Both PDFs are publicly available under
specs.zerodds.org/v1.0-beta1/.

The Beta period is open for community review.

# 01 – Getting Started

Goal: a publisher and a subscriber talking to each other in five
minutes.

Sequence:

1. [Install ZeroDDS](installation.md) — pick your platform.
2. [DDS in 5 minutes](concepts.md) — the four nouns: Domain,
   Topic, Publisher, Subscriber.
3. [First publisher / subscriber](first-publisher.md) — Rust
   hello-world running on `cargo run`.
4. From here: [04 IDL](../04-idl/README.md) (define your own
   types) and [Integration](../README.md) (use a non-Rust language).

# 01 – Getting Started

Goal: build and run a publisher and subscriber from the same candidate checkout.
This is source guidance, not a promise that RC7 distribution packages are published.

Sequence:

1. [Build the examples](installation.md) — Rust toolchain and scoped build.
2. [DDS in 5 minutes](concepts.md) — the four nouns: Domain,
   Topic, Publisher, Subscriber.
3. [First publisher / subscriber](first-publisher.md) — Rust
   hello-world using the maintained executable sources.
4. From here: [04 IDL](../04-idl/README.md) (define your own
   types) and [Integration](../README.md#integration-per-language) (use a non-Rust language).

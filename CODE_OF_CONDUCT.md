# Code of Conduct

This project has adopted the **Contributor Covenant**, version 2.1.

The full text — including the enforcement guidelines, scope, and the
ladder of consequences for conduct violations — is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Reporting

Concerns about contributor conduct in this project's spaces (issues,
pull requests, discussions, mailing lists, chat) should be reported
privately to:

- **Email:** `conduct@zerodds.org`

The maintainer team will respond within five business days. Reports are
handled confidentially. The reporter's identity is not shared with the
person being reported without explicit consent, and retaliation against
reporters is itself a Covenant violation.

## Scope

The Code of Conduct applies to:

- All public project spaces (GitHub repository, Discussions, Issues,
  Pull Requests).
- All private project communication channels designated as
  project-related.
- Public events where individuals represent the project.

# ZeroDDS Python wire runtime

`zerodds-wire` provides `zerodds_wire`, including `TopicDescriptor`, to Python
modules generated by the matching ZeroDDS IDL compiler. It is pure Python and
does not require the native DDS binding for serialization. The native
`zerodds` distribution depends on the matching runtime version.

Build an internal wheel from the repository root:

```sh
python3 -m pip wheel --no-deps --wheel-dir target/wheels runtime/python
```

Install the runtime wheel alongside the native wheel using an offline local
wheel directory. No repository `PYTHONPATH` is required. Python 3.9 is the
minimum because the key-hash implementation uses `hashlib`'s
`usedforsecurity` argument. This metadata is not a claim of verification on
every supported Python version.

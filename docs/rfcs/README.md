# Design RFCs

Groessere technische Vorschlaege, die vor Implementierung formell diskutiert
werden sollen. Verbindlich gemaess `docs/architecture/README.md`.

Abgrenzung zu ADRs: ADRs dokumentieren getroffene Entscheidungen kurz und
retrospektivfaehig; RFCs sind Vorschlaege mit mehr Kontext, Alternativen-
Analyse und Review-Zyklus, oft mehrseitig.

Nummerierung wie ADRs: `NNNN-titel.md`, beginnend bei `0001`.

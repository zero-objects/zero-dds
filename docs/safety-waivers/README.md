# Safety-Waiver-Register

Jeder explizit erteilte Waiver gegen Safety-Regeln aus
`docs/architecture/04_safety_by_architecture.md §2` wird hier dokumentiert.
Verbindlich gemaess §7 desselben Dokuments.

## Format

Eine Datei pro Waiver: `NNNN-kurzer-titel.md`.

## Pflichtinhalte je Waiver

1. **Betroffene Regel** (aus §2.1/§2.2 etc.)
2. **Technische Begruendung** — warum die Regel hier nicht einhaltbar ist
3. **Alternativ-Analyse** — warum andere Wege nicht funktionieren
4. **Risiko-Bewertung** — welche Konsequenzen hat die Ausnahme
5. **Kompensatorische Massnahmen** — z.B. zusaetzliche Tests, Fuzz-Coverage
6. **Zustimmungen** — Safety-Engineering-Lead + unabhaengiger Senior-Engineer
7. **Expiry / Review-Datum**

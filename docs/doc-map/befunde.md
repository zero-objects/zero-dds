# Befunde der Erhebung

Widersprüche zwischen Code, Doku-Kommentaren, Specs, man-Seiten, Beispielen und
Paketdateien, die beim Schreiben der Doku-Map aufgefallen sind. Jeder Eintrag
nennt die Stelle; „gemessen“ heißt, ein gebautes Programm wurde aufgerufen,
sonst ist der Befund aus dem Code gelesen. Die Liste wird abgearbeitet: ein
behobener Befund wird gestrichen. Die Einzelheiten stehen im Abschnitt
„Widersprüche“ der jeweiligen Seite.
